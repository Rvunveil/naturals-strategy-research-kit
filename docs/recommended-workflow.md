# Recommended workflow

## Phase 1 — Frame

Use `deep-research` to turn the challenge into a small set of falsifiable decisions. Record scope, time period, geography, definitions, and the intended decision.

## Phase 2 — Gather and verify

Collect primary sources and append every material claim to the evidence register. Run `source-verification` before using a number in a model or slide.

## Phase 3 — Diagnose the market

Use `market-intelligence` for ecosystem mapping, customer segments, competitor benchmarking, and the market-sizing bridge. Explicitly mark unavailable disclosures.

## Phase 4 — Choose

Use `business-strategy` to generate and compare strategic options, then `financial-modelling` to test the economics and operating constraints.

## Phase 5 — Challenge

Run `critical-review` independently. Any recommendation that fails the downside economics, has no right to win, or depends on an unsupported statistic returns to Phase 2.

## Phase 6 — Communicate

Use `presentation-storytelling` to build the executive narrative, with source notes and an appendix. Re-run `critical-review` against the final deck.

## Minimum handoffs

No material number enters a model without an evidence-register row or an explicitly labelled assumption. No recommendation enters the deck without a decision, an owner, a metric, a test, and a failure threshold.
